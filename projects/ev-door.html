Emergency Door Release Mechanism for Electric Vehicle Fires

Designed and prototyped an independent emergency door-release mechanism intended to remain operable during electric vehicle fire conditions.

Overview

This project explored an independent mechanical emergency-release system for electric vehicle doors. The system detects elevated temperature and activates a pneumatic mechanism to release the door latch without relying on the vehicle's central electrical system.

My Contribution

  • Designed the mechanical release mechanism in SolidWorks
  • Built and tested a physical prototype
  • Conducted 65 experimental trials across 13 test conditions
  • Analyzed reliability and performance data using Python

System Design

The system used temperature detection, relay control, a solenoid valve, compressed air, and a custom mechanical release component.

Testing

Testing evaluated the mechanism under multiple temperature and pressure conditions to determine activation reliability.

Results

The prototype was evaluated through 65 trials across 13 test conditions. Experimental data were analyzed using Python to compare reliability across operating conditions.
