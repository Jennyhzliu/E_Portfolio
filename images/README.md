# Portfolio images

## Adding your profile picture

Upload a square or portrait-oriented photo to this folder and name it exactly
`profile.jpg`. The portfolio homepage is already configured to display that file.

For the best result:

- Use a JPG image that is at least 600 × 600 pixels.
- Keep your face near the center because the image is cropped into a circle.
- Compress the image before uploading so the website loads quickly (under 500 KB
  is a useful target).
- Keep the filename lowercase: `profile.jpg`.

### Uploading through GitHub

1. Open the `images` folder in your GitHub repository.
2. Select **Add file**, then **Upload files**.
3. Drag your picture into the upload area.
4. Make sure its filename is `profile.jpg`.
5. Enter a short commit message and select **Commit changes**.

If you replace the picture later, upload a new file with the same name and choose
to replace the existing file. You do not need to edit the HTML or CSS again.
